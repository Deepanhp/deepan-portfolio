The Two Tools That Stopped Claude from Eating My Wallet (90% Savings, No Joke)

By Deepan Kumar

I still remember the day I opened my Claude API bill and had to sit down.

$1,247.89. For one month. And that was after I thought I’d optimized my workflow. I was running Claude Code 12+ hours a day — PR reviews, code refactors, debugging sessions. I thought I was being efficient.

Turns out, I was hemorrhaging tokens like a fire hose with no shutoff valve.

Here’s the thing nobody tells you about AI coding assistants: they’re incredible… until they’re not. “Not” usually happens when you realize each git status call is dumping 2,000 tokens into your context window for no reason.

That’s when I found RTK and Context Mode. Two tools that sound boring but are actually token assassins.

❌ What I Was Doing Wrong (And You Probably Are Too)

Sin #1: Death by a Thousand cat Commands

Every time Claude needed to see a file, it would cat the entire thing. 50 lines? Sure. 500 lines? Why not. 5,000 lines of minified JSON? Chef's kiss of token waste.

Sin #2: The Git Status Spam

Running git status multiple times per conversation. Each time? Full output. Every. Single. File. 847 tokens of file paths I didn't need.

Sin #3: The Grep Avalanche

Searching for something in the codebase? Here are 4,000 lines of matches, most irrelevant. Enjoy your context flood.

Sin #4: Web Fetching Like It’s 1999

curl commands dumping entire HTML responses—ads, scripts, tracking pixels—straight into context. Beautiful.

The Result? By the time I discovered RTK, I’d burned through over $4,000 in three months. That’s a used car. That’s rent in some cities. That’s a lot of coffee I didn’t buy because I was paying for AI to read git status 47 times a day.

🔪 Enter RTK: The Rust Token Killer

RTK stands for Rust Token Killer. Think of it as a smart filter that sits between Claude and your terminal commands — it intercepts common dev commands and returns only what matters.

Instead of a wall of verbose git status output, you get:

Modified: 43 files | Staged: 0 files | Untracked: 2 files

Tokens saved: ~800 per call

The Hook That Changes Everything

RTK works through a Claude Code hook. Add this to your .claude/settings.json:

{ "hooks": { "beforeToolUse": { "Bash": "rtk proxy $COMMAND" } } }

Now every shell command Claude runs gets filtered through RTK automatically. Zero effort. Maximum savings.

Real-World Numbers (My Actual Stats)

Total commands: 16,122 | Input tokens: 1.52B | Tokens saved: 1.04 billion (68.8%)

Yes. 1.04 BILLION tokens saved. At $3–15 per million tokens, that’s $3,000–15,000 saved over 6 months.

🛡️ Context Mode: The Bouncer for Your Context Window

RTK handles command output. Context Mode handles everything else. It’s an MCP plugin that blocks context floods before they happen.

It intercepts curl/wget calls (redirects to sandboxed fetch), large file reads over 500 lines (indexes + search), grep with 100+ results (summarizes), and web fetches (chunks and lets you query).

The Batch Execute Superpower

Instead of four separate terminal commands flooding your context, you batch them into a single indexed call. Tokens used: ~500 vs. 8,000+ the old way.

🚀 How to Set This Up (10 Minutes)

Step 1: brew install rtk or cargo install rtk
Run rtk gain to confirm the right package (naming collision with Rust Type Kit).

Step 2: Add the beforeToolUse Bash hook to ~/.claude/settings.json pointing to rtk proxy.

Step 3: npm install -g @context-mode/mcp and configure in Claude Code MCP settings.

Step 4: Run rtk gain after a week and watch the numbers climb.

🎯 When to Use What

Reach for RTK on git commands, directory listings, test output, build logsanything Claude runs repeatedly.

Reach for Context Mode on web scraping, large file analysis, multi-command workflows, and big DB results.

Skip both for small file edits, single-line outputs, or commands you’re running manually.

🤔 The Surprising Side Effect

Beyond cost savings Claude got better at its job. With less noise in the context window, responses became more focused, faster, and more accurate. It’s like cleaning your desk before you work. Sure, you can work in chaos, but why?

🧠 The Meta Lesson

The best AI optimization isn’t about prompts. It’s about plumbing.

Everyone obsesses over writing the perfect prompt. But if your infrastructure is spewing tokens like a broken fire hydrant, no amount of prompt engineering will save you. Fix the pipes first. Then worry about the faucets.

💡 Do These Three Things Today

1. Install RTK — 5 minutes, instant savings
2. Add the Bash hook — one line in settings.json
3. Run rtk gain after a week — watch the numbers and feel smug

RTK alone saved me 68.8% across 16,000+ commands. That’s real money back in your pocket.

🎬 Final Thoughts

AI coding assistants are incredible tools. But they’re also incredibly expensive if you let them be. RTK and Context Mode aren’t magic, they’re smart defaults that should probably be built into Claude Code from day one, but aren’t yet.

Until then: install these, save money, and buy coffee/beer with the difference.

Your wallet will thank you.
